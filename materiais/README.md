# Materiais CE.X

## Como funciona

1. **Jogue o conteúdo bruto em `/brutos/`** — txt, md, pdf, docx, qualquer formato
2. **Avise o Claude Code** que tem material novo
3. **Receba em `/prontos/`** o material finalizado no padrão visual da CE.X

## O que o Claude entrega

| Tipo | Formato de saída |
|---|---|
| PDF | HTML estilizado (abrir no browser → imprimir → Salvar como PDF) |
| Apresentação | HTML por slides ou conteúdo organizado para colar no PowerPoint/Canva |

## Padrão visual aplicado

Todo material segue o CE.X Brand Book v3.2:
- Fundo `--ink` (#0E110D) ou `--cream` (#EDE6D3)
- Acento oliva (#7A9E3F) — máx. 12% da peça
- Tipografia Inter exclusiva
- Sem emojis decorativos
