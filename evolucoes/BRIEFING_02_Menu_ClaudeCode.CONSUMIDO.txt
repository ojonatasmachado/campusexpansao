# Briefing 02 — Correção do MENU (CE.X · Página de Venda)

Complemento ao BRIEFING_PaginaVenda_ClaudeCode.txt. Este arquivo corrige a navegação
do topo. Se houver conflito, ESTE arquivo prevalece sobre o menu descrito antes.

================================================================================
PROBLEMA A CORRIGIR
================================================================================

O menu atual é: Início · Materiais · Cursos · Séries · Loja · Sobre

Isso quebra a lógica do projeto. "Materiais", "Séries" e "Loja" levam todos ao MESMO
lugar (o catálogo), e ainda repetem o que o filtro de 2 andares já faz dentro da página.
Categoria NÃO é item de menu — categoria é filtro DENTRO da página. O menu é só para os
grandes mundos do negócio.

================================================================================
MENU CORRETO
================================================================================

Início · Materiais · Cursos & Mentorias · Sobre

- Início            -> home / apresentação da CE.X
- Materiais         -> ESTA página (o catálogo inteiro: Para ministrar + Para liderar +
                       Eventos). É aqui que mora o filtro de 2 andares.
- Cursos & Mentorias-> bloco "ao vivo" (turma, data, vaga, ticket mais alto). Lógica de
                       compra diferente da compra única. Pode ser só "Em breve" por agora.
- Sobre             -> a CE.X, a tese "Nós preparamos. Deus multiplica."

REMOVER do menu: "Séries" e "Loja".
- "Séries" vira o filtro interno "Para ministrar" (organizado por público).
- "Loja" NÃO é um bom nome (comercial demais para o tom ministerial e vago demais). A
  página é o próprio catálogo, então ela se chama "Materiais". Não usar "Loja".

================================================================================
BOTÃO "COMECE AGORA"
================================================================================

Manter. Deve rolar/levar para o catálogo de Materiais (ou para o material carro-chefe).
Não criar uma página nova só para ele.

================================================================================
REGRA GERAL (fixar)
================================================================================

- Menu = grandes mundos (Materiais prontos x Ao vivo x Sobre).
- Filtro de 2 andares (Para ministrar / Para liderar / Eventos -> público/função) = a
  navegação fina, sempre DENTRO da página Materiais.
- Nunca transformar uma categoria/sub em item de menu do topo.
