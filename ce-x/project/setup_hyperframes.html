01 · Setup único

Instalar uma vez.

Três coisas: Node.js (motor), FFmpeg (renderizador de vídeo), HyperFrames (framework). 15 minutos no máximo.

1.1 · Instalar Node.js e FFmpeg
Terminal
Esses são os dois "motores" que o HyperFrames precisa. Mais simples no Mac via Homebrew. Se você não tem Homebrew, instala primeiro.
Terminal · macOS # Se ainda não tem o Homebrew (gerenciador de pacotes do Mac): /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Instalar Node.js (versão 22 ou maior) e FFmpeg: brew install node ffmpeg # Verificar se deu certo (precisa retornar v22 ou maior): node --version ffmpeg -version
PowerShell · Windows # Baixar e instalar: # 1. Node.js: https://nodejs.org → "LTS" → próximo, próximo, instalar # 2. FFmpeg: https://www.gyan.dev/ffmpeg/builds/ → "release builds" → essentials # Descompacta em C:\ffmpeg e adiciona C:\ffmpeg\bin no PATH do sistema. # Depois, verificar: node --version ffmpeg -version
!
No Windows, recomendo usar o WSL2 (Ubuntu) ao invés. Roda mais estável e os comandos viram iguais aos do Mac. Pesquisa "instalar WSL2 ubuntu" — Microsoft tem guia oficial.
1.2 · Criar a pasta do projeto
Terminal · 1x
Uma pasta na sua máquina onde TODOS os seus reels vão morar. Cada reel é uma sub-pasta.
Terminal # Vai pro diretório onde você quer guardar (Documentos é uma boa): cd ~/Documents # Cria a pasta e entra: mkdir cex-reels && cd cex-reels # Inicializa um projeto HyperFrames de exemplo: npx hyperframes init reel-01 --non-interactive --example blank # O comando acima cria a pasta reel-01/ com um composition base. # Daqui pra frente, cada novo reel é uma sub-pasta nova.
1.3 · Render de teste
Validação
Gera um MP4 do projeto de exemplo só pra garantir que tudo funciona. Se sair vídeo, tá tudo certo.
Terminal # Entra na pasta do reel: cd reel-01 # Roda o render — sai um MP4 em ./renders/ npx hyperframes render # Abre o resultado no Finder: open renders
✓
Se o MP4 abrir e tocar — setup completo. Daqui pra frente, todo reel novo é só repetir o passo 1.2 (criar pasta) e me pedir pra gerar a composition.
02 · Por cada reel

O ciclo de produção.

Depois do setup, cada reel novo segue este loop. Tempo médio: 8 minutos de ponta a ponta (a maior parte é gravação + render).

2.1 · Grava no celular
~3 min
Modo vertical, câmera frontal, boa luz. Foca em uma tese. Estrutura recomendada: gancho (3s) → tese (5s) → exemplo (15s) → versículo/citação (5s) → aplicação (10s) → CTA (5s). Total entre 30 e 60 segundos.
▸
Anota mentalmente onde estão os picos da fala — momentos em que você quer um overlay aparecer (uma estatística, uma palavra-chave, um versículo). Vai te ajudar na hora de me pedir a composition.
2.2 · AirDrop pro Mac
~30s
Envia o vídeo do celular pro Mac. Salva como face-cam.mp4 dentro de uma nova pasta de reel:
Terminal # Cria pasta do novo reel: cd ~/Documents/cex-reels npx hyperframes init reel-02 --non-interactive --example blank cd reel-02 # Move o vídeo do AirDrop pra cá (ajuste o nome): mv ~/Downloads/IMG_1234.MOV ./face-cam.mp4
2.3 · Me manda a transcrição
Claude Desktop
Aqui no Claude Desktop, manda: "Cláudio, novo reel — segue transcrição [cola o que você falou]. Duração: 45s. Picos: 'estrutura' aos 12s, '73%' aos 28s, versículo Mateus 9.38 aos 35s."
Eu te devolvo um index.html — a composition HyperFrames pronta pra renderizar. Você copia o arquivo todo e cola dentro da pasta reel-02/ substituindo o que tem lá.
▸
Não precisa transcrever tudo. Manda só os momentos-chave e os timestamps aproximados. Pra detalhes finos, conversa comigo iterativamente.
2.4 · Render
~60s
Um comando. Você espera, o MP4 sai pronto com sua face cam e os overlays já compostos em cima. Nada de CapCut.
Terminal # Dentro da pasta reel-02/: npx hyperframes render # Resultado em ./renders/. Abre pra ver: open renders
▸
Quer ver antes de renderizar? Roda npx hyperframes preview em vez de render. Abre o navegador com a animação rolando ao vivo. Útil pra ajustes.
2.5 · Posta
~1 min
AirDrop o MP4 do Mac pro celular. Abre o Instagram, novo Reel, sobe o vídeo, escreve a legenda, publica. Pronto.

04 · Dúvidas comuns

O que perguntam.

E se eu não souber nada de terminal?
Os comandos deste guia são literais — você copia e cola. Não precisa entender, só seguir. Em 3-4 reels você já vai pegar o ritmo. Se travar em algo, me manda print do terminal aqui no chat e eu te ajudo.
E se o render der erro?
Roda npx hyperframes doctor — ele te diz o que tá faltando. 90% dos erros são Node desatualizado ou FFmpeg fora do PATH. Me manda a saída do doctor que eu interpreto.
Posso editar a composition manualmente depois?
Sim. O HTML que eu te entregar é editável. Mexer em texto é fácil — abre num editor (TextEdit, VS Code) e troca. Pra ajustes finos de animação, me chama.
Renderiza em quanto tempo?
Reel de 60s renderiza em ~45-90 segundos no Mac M1/M2. Mais lento em máquinas antigas. Pra acelerar testes, roda npx hyperframes render --quality draft.
Funciona no iPad ou só no Mac?
Só Mac/PC. iPad não roda Node.js nativo (sem trapaça). Mas você grava no iPhone e renderiza no Mac, que é o fluxo previsto.
E os carrosséis estáticos? Servem aqui?
Não — pra posts estáticos, você usa o Brand Book e o Reel Composer. O HyperFrames é só pros reels animados com vídeo de fundo.
